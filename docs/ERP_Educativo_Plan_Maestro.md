# ERP EDUCATIVO - PLAN MAESTRO DE DESARROLLO

## Objetivo

Transformar el actual Leccionario Digital en un ERP Educativo Integral para instituciones educativas del Ecuador.

---
# Arquitectura General

## Tecnologías
- Backend: Spring Boot
- Frontend: Angular
- Mobile: Flutter
- Base de datos: PostgreSQL
- Seguridad: JWT + Roles + Permisos
- Auditoría completa
- Multiinstitución

Cada módulo deberá cumplir con:

- CRUD completo
- Auditoría
- Historial de cambios
- Permisos granulares
- Importación/Exportación Excel
- Reportes PDF
- API REST
- Compatible con App móvil cuando aplique
- Dashboard con indicadores
- Bitácora de acciones
