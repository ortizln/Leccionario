# MANUAL MAESTRO DE DESARROLLO
# ERP EDUCATIVO

> Este documento define el estándar obligatorio que deberá seguir cualquier IA durante el desarrollo del ERP Educativo.

---

# OBJETIVO

Construir un ERP Educativo profesional, escalable, modular y preparado para múltiples instituciones educativas utilizando:

- Backend: Spring Boot 3 + Java 21
- Frontend: Angular 18+
- Mobile: Flutter
- PostgreSQL
- Docker
- JWT
- Clean Architecture
- DDD
- SOLID

No se permitirá código improvisado.

---
